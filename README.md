# SEN Support Platform

Разработка цифровой платформы поддержки семей с детьми с особыми образовательными потребностями с функциями планирования занятий, координации сопровождения и ведения индивидуального дневника развития[cite: 2].

- Жұмағали Бейбарыс Айбекұлы (SE-2423) — Backend Development и архитектура системы[cite: 2]
- Жұпарбай Еркебұлан Ермекұлы (SE-2423) — Frontend Development и UX-проектирование[cite: 2]

## Направления работы Ақнұр (Security, Privacy & Quality Assurance):
- Проектирование privacy-by-design, моделирование угроз, шифрование и соблюдение требований законодательства о персональных данных (РК и GDPR)[cite: 2].
- Разработка модели ролевого доступа (RBAC) для разграничения прав родителя, специалиста, администратора и гостя[cite: 2].
- Проектирование аутентификации, безопасного управления сессиями и реализации журнала аудита действий с данными ребенка[cite: 2].
- Тестирование системы на уязвимости (OWASP Top 10), проверка прав доступа, автоматизированные и нагрузочные тесты[cite: 2].

## Технологический стек:
- Frontend: React / TypeScript[cite: 2]
- Backend: Node.js / Express[cite: 2]
- Безопасность и качество: JWT, RBAC, OWASP тестирование, Jest[cite: 2]

## Структура репозитория:
- `/docs` — документация для предзащиты и отчеты по безопасности
- `/src/client` — клиентская часть (Frontend)[cite: 2]
- `/src/server` — серверная часть и API (Backend)[cite: 2]
- `/tests` — тесты и проверки качества
