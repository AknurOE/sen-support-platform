# SEN Support Platform

Разработка цифровой платформы поддержки семей с детьми с особыми образовательными потребностями с функциями планирования занятий, координации сопровождения и ведения индивидуального дневника развития.

## Направления работы Ақнұр (Security, Privacy & Quality Assurance):
- Проектирование privacy-by-design, моделирование угроз, шифрование и соблюдение требований законодательства о персональных данных (РК и GDPR).
- Разработка модели ролевого доступа (RBAC) для разграничения прав родителя, специалиста, администратора и гостя.
- Проектирование аутентификации, безопасного управления сессиями и реализации журнала аудита действий с данными ребенка.
- Тестирование системы на уязвимости (OWASP Top 10), проверка прав доступа, автоматизированные и нагрузочные тесты.

## Технологический стек:
- Frontend: React / TypeScript
- Backend: Go (стандартная библиотека, `net/http`)
- Безопасность и качество: JWT, RBAC, OWASP тестирование, Go testing

## Структура репозитория:
- `/docs` — документация для предзащиты и отчеты по безопасности
- `/frontend` — клиентская часть на React, TypeScript и Vite
- `/backend/cmd/api` — точка входа API-сервера
- `/backend/internal/config` — загрузка и проверка конфигурации
- `/backend/internal/domain` — доменные модели и типы
- `/backend/internal/service` — бизнес-правила и прикладные сценарии
- `/backend/internal/repository` — доступ к данным
- `/backend/internal/transport/http` — HTTP-обработчики на стандартной библиотеке Go
- `/backend/migrations` — миграции базы данных
- `/backend/tests/integration` — интеграционные тесты

## План разработки backend

1. Фундамент: структура Go-проекта, конфигурация, подключение PostgreSQL, миграции, логирование и обработка ошибок.
2. Доступ: регистрация, вход, JWT, безопасное хранение паролей и RBAC для родителя, специалиста и администратора.
3. Профили: учётные записи, профили детей и безопасные связи между родителем, ребёнком и специалистом.
4. Сопровождение: планирование и ведение занятий, статусы и координация участников.
5. Дневник: записи о развитии ребёнка, видимость записей и история изменений.
6. Качество и запуск: аудит действий, тесты, проверка OWASP-рисков, Docker и документация API.

На текущем этапе добавлены только черновые доменные модели. API, база данных и бизнес-логика ещё не реализованы.

## Запуск frontend

```bash
cd frontend
npm install
npm run dev
```

Frontend собран на React, TypeScript и Vite. Стартовый экран является временной основой для будущих сценариев родителя, специалиста и администратора.
