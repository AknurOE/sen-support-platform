# SEN Support Platform

Разработка цифровой платформы поддержки семей с детьми с особыми образовательными потребностями с функциями планирования занятий, координации сопровождения и ведения индивидуального дневника развития.

## Команда и роли:
- Ондасын Ақнұр Еркінқызы (SE-2420) — Security, Privacy & Quality Assurance
- Жұмағали Бейбарыс Айбекұлы (SE-2423) — Backend Development и архитектура системы
- Жұпарбай Еркебұлан Ермекұлы (SE-2423) — Frontend Development и UX-проектирование
- Научный руководитель: Сеньор-лектор Макатов Арстан Кутжанович

## Направления работы Ақнұр (Security, Privacy & Quality Assurance):
- Проектирование privacy-by-design, моделирование угроз, шифрование и соблюдение требований законодательства о персональных данных (РК и GDPR).
- Разработка модели ролевого доступа (RBAC) для разграничения прав родителя, специалиста, администратора и гостя.
- Проектирование аутентификации, безопасного управления сессиями и реализации журнала аудита действий с данными ребенка.
- Тестирование системы на уязвимости (OWASP Top 10), проверка прав доступа, автоматизированные и нагрузочные тесты.

## Технологический стек:
- Frontend: React / TypeScript
- Backend: Node.js / Express
- Безопасность и качество: JWT, RBAC, OWASP тестирование, Jest

## Структура репозитория:
- `/docs` — документация для предзащиты и отчеты по безопасности
- `/src/client` — клиентская часть (Frontend)
- `/src/server` — серверная часть и API (Backend)
- `/tests` — тесты и проверки качества
